「竹芎林」位在大禮堂和工程一館之間的草地上，從旁邊原本設有的步道至竹芎林本體有一條小小的行走痕跡，在裝置中還有一圈更明顯的環形痕跡。<br>
除了視覺上有明顯的草及土壤的界線，其中還有裝置發出的聲響，在裝置底下也能感受到在陰影下的溫差。

## FRICTION｜摩擦

<!-- 描述一個沒有如預期發生的瞬間。 -->
在清交校園生活了六、七年，對 Desire Path 其實很熟悉。平常趕課、抄捷徑或躲避陽光時，我也常常走在這些沒有被正式規劃的路徑上。但當這次被要求在短時間內找出一條時，我反而一時想不起來，尋找了一陣子才注意到，原來平常經過的「竹芎林」旁就存在這樣的痕跡。另一個困難是非視覺的感官紀錄，因為 Desire Path 最直接的觀察方式就是視覺，我們可以很清出的「看見」他與一般路徑的差異，當視覺不再是唯一的觀察方式時，我一開始反而不知道還能注意什麼。

## CONNECTION｜連結

<!-- 選擇本週閱讀或課堂案例中的一個概念。它如何改變你對上述瞬間的理解？ -->
這次尋找 Desire Path 的過程讓我想到 Ginzburg 所談的「線索」。他提到，有些事情不是透過最顯眼的特徵被理解，反而是從容易被忽略的細節中留下痕跡，再由這些痕跡推知曾經發生的事情。Desire Path 也是如此，被踩平的草、裸露的泥土或一條不在規劃中的路徑，都記錄了人實際使用空間的方式。它沒有被刻意設計出來，卻因為人們一次次選擇比較方便的行走方式而形成，並慢慢融入我們的日常生活，也超出了原本設計者對空間的預期。<br>

另一方面，Haraway 的 situated knowledges 也讓我重新思考「觀察」這件事。她認為觀看與知識都來自具體而有限的位置，而不是一個可以從外部看見全部的視角。當我不只用眼睛辨認路徑，而是實際站在竹芎林裡，注意裝置的聲音、陰影下的溫差以及身體所在的位置時，對這個場域的理解也變得不太一樣。原本只是「看到一條被走出來的路」，後來更像是透過自己的身體，感受到人在這個空間裡如何移動、停留，以及環境如何回應這些行為。

## NEXT MOVE｜下一步

<!-- 如果把這個發現轉化成工具、介面、規則、身體技術或作品，你下一步會測試什麼？ -->
如果將這次的觀察繼續發展，我會想記錄校園中更多 Desire Path，並比較它們形成的位置與周遭環境，例如原本步道的方向、遮蔭、距離，以及人們為什麼選擇從這裡經過。除了拍攝已經形成的路徑，也可以在不同時段實際走過這些地方，記錄聲音、溫度、地面觸感與身體移動的差異，測試是否能用一些簡單的提示，例如放置物件、改變行走方向或設置暫時性的標記，觀察人會繼續沿著既有路徑前進，還是產生另一條新的路徑。比起直接「設計一條路」，我更想觀察人在沒有明確指示的情況下，如何用自己的選擇慢慢改變原本被規劃好的空間。
